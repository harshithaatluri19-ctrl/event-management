ABOUT OUR PROJECT

Making College Event Management Simple

Harshitha Event Hub is a College Event Management System designed to help organize campus events in one convenient place.

The application supports event creation, event listing, searching, updating, deleting and optional photo uploads. It uses HTML, CSS and JavaScript for the interface, Node.js and Express for the server, and MySQL to store event information.
